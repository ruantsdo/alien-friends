# 👽 Aliens Friends

> Projeto criado como prática a partir de um dos desafios do curso **Zero To Mastery** na Udemy, com foco em requisições a múltiplas APIs e integração dinâmica de dados.

---

## 🚀 Sobre o Projeto
O **Aliens Friends** é um projeto de aprendizado que demonstra:  
- 🌌 **Geração de aliens aleatórios** a partir de múltiplas APIs.  
- 🔍 **Campo de busca funcional** para filtrar resultados dinamicamente.  
- 🎨 **Interface limpa e responsiva**, construída para facilitar a visualização dos dados.  
- 💻 **TypeScript aplicado** para reforçar boas práticas e tipagem em React, mesmo o curso original usando JavaScript puro.  

---

## 🛠️ Tecnologias Utilizadas
- **Front-end:** React.js  
- **Linguagem:** TypeScript  
- **Estilo:** Tachyons, CSS

## 📂 Aprendizados
Durante o desenvolvimento do projeto, pratiquei:  
- Consumo de **múltiplas APIs** e integração de dados de forma dinâmica.  
- Uso de **TypeScript em React** para tipagem de componentes e props.  
- Construção de **interfaces simples e responsivas** com Tachyons e CSS.  
- Manipulação de estado e renderização condicional de componentes.
